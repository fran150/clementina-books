# A. BASIC keywords

Every keyword of Clementina BASIC, with its form and what it does, in one
line each. Square brackets mark parts you may leave out. The
*Programmer's Reference Guide* explains each one in full, with examples.

Most keywords can be typed in lowercase. A variable name may not contain a
keyword: `TOTAL` contains `TO`, so it gives `?SYNTAX ERROR`.
