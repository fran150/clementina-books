# B. Error messages

When BASIC stops with an error, it prints the message and, for a program,
`IN` and the line number: `?SYNTAX ERROR IN 20`. The "Raised when" column
says what usually causes each one. [Troubleshooting](../troubleshooting.md)
has advice for the most common.

{{#include ../../../tables/basic-errors.md}}

MIA keeps its own error codes, about Wi-Fi, the SD card and its
hardware. They appear on its USB console, not on the screen;
[Troubleshooting](../troubleshooting.md#mias-error-codes) explains the ones
a user meets.
