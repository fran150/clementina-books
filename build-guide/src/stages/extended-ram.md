# Stage 7: Extended RAM

The AS6C4008 holds 512 KB, seen by the CPU through a 16 KB window at
`$8000-$BFFF`. The VIA's PA0-PA4 pick which of its 32 banks shows in the
window. The VIA comes in stage 8, so for now those five pins go to GND and
the window shows bank 0. That's all BASIC needs: it uses bank 0 as the top
of its workspace, where it keeps its strings, so this stage is the one that
makes BASIC complete.

## What you add

The extended RAM (U2, AS6C4008) on board 2, after the base RAM, with its 100 nF
capacitor. It takes all its bus lines from the base RAM's (U4) free holes:
D0-D7, A0-A13 and the strobes `~OE` and `~WE`. Leave a free hole in each of
its D0-D7 and A0-A3 rows: the VIA takes them from here in stage 8 (see
[Chain, don't star](../breadboard.md#chain-dont-star)). Its top five address
lines are the bank number, and they sit on scattered pins: watch those rows.

- **U2** goes on board 2 in columns 40-55, notch toward column 1, right under
  the VIA. Its incoming wires land in row a (top pins) or row j (bottom).
- **Everything but `~EXRAMCS` comes from U4**, from its free holes (row b
  on top, row i underneath). That uses the last free hole in each U4 row.
- **U2's own rows keep one free hole** for D0-D7 and A0-A3 (row b on top,
  row i underneath): the VIA's wires leave from there in stage 8.
- **`~EXRAMCS`** comes down from U7.3 (74AC08) on board 3, through the gap
  between U6 and where the VIA will go.
- **The bank pins** (1, 2, 3, 30 and 31) get a short black wire each to the
  nearest GND rail, in the same holes the VIA's wires will use later.
- **Take the stage 4 LEDs off first** if they are still in columns 40-55.
- **Route between the chips:** the wires from U4 run in the channels above
  and below board 2, and drop into U2's rows from outside. Nothing crosses
  over U4 or U2.
- **The 100 nF capacitor** goes across the rails at column 39, beside pin 32's
  red wire.

The CPU's A14 and A15 don't go to the AS6C4008 (U2): the window is 16 KB, so the chip sees
A0-A13 from the CPU, and its own A14-A18 are the bank number.

### Just for this stage

- **The bank pins to GND.** Put a black wire from each of U2.1, U2.2, U2.3,
  U2.30 and U2.31 to GND. That holds A14-A18 low, so the window always
  shows bank 0. In stage 8 each of these wires gives way to a green one
  from the VIA's port A.

The kernel writes the bank number to the VIA at every reset. With no VIA
yet, those writes go nowhere, which is harmless.

### BASIC

1. Plug in, start the video client, and press RESET. `23647 BYTES FREE` is
   the same as in stage 6: BASIC counted bank 0 from the start, it just
   couldn't use it until now.
2. Now strings work. `PRINT "HELLO"` prints `HELLO`, and:

   ```basic
   A$="CLEMEN"+"TINA":PRINT A$
   ```

   ```text
   CLEMENTINA
   ```

   The joined string is built at the top of bank 0, just under `$C000`.
3. Fill the window with strings and check them all. Type this program,
   then `RUN` (it takes a few seconds):

   <!-- example: cycles=80000000 -->
   ```basic
   10 B$="ABCDEFGHIJKLMNOPQRSTUVWXYZ"
   20 B$=B$+B$+B$+B$:DIM A$(69)
   30 FOR I=0 TO 69:A$(I)=B$+STR$(I):NEXT
   40 FOR I=0 TO 69
   50 IF A$(I)<>B$+STR$(I) THEN PRINT "BAD";I
   60 NEXT:PRINT "DONE"
   ```

   ```text
   DONE
   ```

   It prints `DONE` and no `BAD` line. Clementina's strings keep a display
   attribute with every character, two bytes each, so the 70 strings of 108
   characters fill some 15 KB, from `$C000` down: nearly all of bank 0.

### The window's top line

The string test fills the window from the top down, so it may not reach
`$8000`. In WozMon (`MON`), check the window's own A13: store `8000: 00`,
then `A000: 0E`, then read `8000`: still `00`. If it reads `0E`, A13 is open
at U2.28.

Press RESET to go back to BASIC.

The bank lines get their own test in stage 8, once the VIA drives them.

the base RAM's U4.27 in stage 6: the same gate drives both, so they should look alike.

## If it fails

| Symptom | Likely cause |
| --- | --- |
| `PRINT "HELLO"` still prints garbage | U2 not selected: probe U2.22 for `~EXRAMCS` pulses, check U7.3 |
| Strings break only in the big test | An address line open at U2 (the base RAM test doesn't cover U2's pins) |
| Strings work, then go wrong after a while | A bank pin's GND wire missing: that pin floats and the bank drifts |
| WozMon writes in stage 6's test now fail | A wire pulled out of a U4 row while adding U2's: re-seat it |
